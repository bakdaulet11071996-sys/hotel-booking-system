# Hotel Booking System Requirements

## Functional Requirements
1. User registration and login
2. Search available hotel rooms
3. View room details and prices
4. Book a hotel room
5. View and cancel bookings
6. Manage hotel rooms
7. Manage customer bookings
8. View booking reports

## Non-functional Requirements
1. Simple user interface
2. Secure password storage
3. Fast room search
4. Mobile-friendly design
5. Reliable data storage
