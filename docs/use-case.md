# Hotel Booking Use Cases

## Actors
- Guest
- Hotel Administrator
- Manager
- System Administrator

## UC-01: Search Rooms
The guest enters check-in and check-out dates.
The system displays available rooms.

## UC-02: Book Room
The guest selects an available room.
The system saves the booking and shows confirmation.

## UC-03: Manage Rooms
The administrator adds or updates room information.
The system saves the changes.
